# RecallRelay AI Lab

프롬프트 버전 비교와 후속 AI 기능의 초기 실험을 보관합니다. 기존 노트북의 3개 개발 사례, 수기 판정표와 `v3 100%` 표시는 작은 개발 집합의 과거 실험입니다. 독립 평가 정확도나 운영 성능으로 해석하지 않습니다. 프롬프트별 생성 조건·재실행 변동·독립 평가자 일치도는 충분히 기록되지 않았습니다.

## API 없이 재검산

Python 3.11 이상, 추가 의존성이나 API 키 없이 저장된 응답만 검사합니다.

```sh
python ai-lab/evaluate.py --output ai-lab/results/offline_recheck.json
python -m unittest discover -s ai-lab/tests -p 'test_*.py' -v
```

JSON 파싱, 현재 스키마, 원문 증거의 정확한 부분 문자열 일치, 날짜/조건 문구의 원문 포함 여부를 검증합니다. 이것은 의미상 정확도를 대신하지 않습니다. 날짜 표현이 동의어이면 보수적으로 실패할 수 있습니다. `exists=false`의 정확성도 자동으로 판정하지 않습니다.

수동 판정을 추가하려면 `--human reviews.json`을 사용합니다. 키는 `A/v3` 형식이며 값은 `{"response_sha256":"응답 원문 UTF-8의 SHA256", "judgments":{"...":"..."}}`입니다. 응답이 바뀌면 해시가 달라져 기존 판정 재사용을 거부합니다. 기존 수기 CSV는 해시가 없어 자동으로 새 결과에 합치지 않습니다.

## 다음 평가의 기준

- 개발 예시와 분리한 미사용 사례 및 다국어·누락 정보·상충 기록 사례를 수집
- 모델 ID, 프롬프트 해시, 입력 해시, 생성 파라미터, 원문 응답, 실행 시간을 함께 기록
- 케이스별 정답·증거 구간·불확실 응답 기준을 사전 작성하고 독립 검수
- 프롬프트 선택 후 고정한 테스트 집합에서 반복 실행과 오류 유형별 결과 보고

위 계획은 아직 새 API 실험이나 독립 평가를 실행했다는 뜻이 아닙니다. 현재 보고서는 원래 저장된 9개 응답을 다시 검산한 결과입니다.
