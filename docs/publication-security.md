# 공개 스냅샷과 로컬 자격증명

고객명, 직원 연락처, VIN 형태의 고객관리 자료는 작성자가 mock 데이터라고 확인했습니다. 직원 이메일은 `.example` 도메인을 사용합니다. 원본의 과거 기록과 고정 자격증명은 이 공개 스냅샷에 포함하지 않습니다.

- 실제 AI API 키는 서버의 `OPENAI_API_KEY` 환경변수나 AI Lab의 숨김 입력으로만 설정합니다. 키를 코드, 노트북 셀·출력, 프런트엔드 `VITE_` 변수에 넣으면 안 됩니다.
- `.env`, `.env.*`, 개인키, 로컬 자격증명 파일, 노트북 자동 저장 폴더는 `.gitignore`로 제외합니다. 빈 설정 예시만 추적합니다.
- DB 비밀번호와 JWT 키는 환경변수로 필수 지정합니다. 공개 DB 설정에는 기본 비밀번호가 없습니다.
- seed 직원은 비활성이고 비밀번호는 미설정 상태입니다. 실제 로그인은 새 비밀번호의 BCrypt 해시를 로컬에서 설정한 뒤 사용합니다. 사전 발급 관리자 코드와 그 해시도 제거했습니다.
- 화면 미리보기에는 비밀번호가 필요하지 않습니다. 회원가입 미리보기 확인값은 브라우저에서 매번 생성되며 백엔드 접근 권한을 부여하지 않습니다.
- 알려진 키 패턴과 고정 데모 자격증명의 잔존 여부를 점검했습니다. 이는 종합 보안 감사나 운영 배포 검증을 대신하지 않습니다.

`.gitignore`는 이미 저장한 파일이나 과거 커밋을 지우지 않습니다. 실제 키를 커밋했다면 먼저 키를 폐기·교체하고 기록 노출 범위를 별도로 처리해야 합니다.
